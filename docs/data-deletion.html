Data Deletion Instructions — Threads Keyword Alert Bot

Last updated: November 25, 2026

Threads Keyword Alert Bot stores a minimal amount of data locally (public post identifiers and matching metadata) to avoid sending duplicate alerts. No data is stored on external servers.

How to request deletion

  1. Send an email to anhlt1908@users.noreply.github.com with the subject line: Data deletion request.
  2. Include your Threads username (for example, @your_username) so the Operator can locate any related records.
  3. The Operator will delete the related records from the local database and revoke any stored access token within 30 days, and confirm by email.

Revoking app access yourself

You can also revoke the App's access to your Threads account at any time:

  1. Open threads.com/settings/account.
  2. Go to Website permissions.
  3. Remove Threads Keyword Alert Bot from the list of authorized apps.
