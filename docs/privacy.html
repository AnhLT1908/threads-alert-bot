Privacy Policy — Threads Keyword Alert Bot

Last updated: November 25, 2026

Threads Keyword Alert Bot ("the App") is a personal, non-commercial application operated by Le Anh Tuan ("the Operator"). The App searches publicly available Threads posts by keyword and sends an alert to the Operator's private Telegram chat when a matching post is found.

1. What data the App processes

  • Public Threads posts returned by the official Threads API keyword search: post ID, post text, username, permalink and timestamp.
  • Access tokens issued by Meta for the Operator's own Threads account.

The App does not collect passwords, private messages, contact lists, location data or any other personal data. It only reads content that is already public on Threads.

2. How data is used

  • To detect whether a public post contains one of the configured keywords.
  • To send a notification (post text excerpt, username and link) to the Operator's Telegram chat.

Data is used solely for this purpose. It is not used for advertising, profiling or any automated decision-making about individuals.

3. Data storage and retention

The App stores post identifiers and matching metadata in a local SQLite database on the Operator's own computer, solely to avoid duplicate alerts. Public post data is retained only as long as needed for this purpose. Access tokens are stored in a local configuration file on the same computer.

4. Data sharing

The App does not sell, rent or share data with third parties. Alert messages are delivered through Telegram's Bot API as a messaging transport only. No data is transferred to any other external service.

5. Cookies and tracking

The App is a server-side process and does not use cookies, analytics or tracking technologies. This policy page itself uses no cookies.

6. Data deletion

To request deletion of any data processed by the App, see the Data Deletion Instructions page. Requests are handled within 30 days.

7. Children's privacy

The App is not directed to children under 13 and does not knowingly process their data.

8. Changes to this policy

Any changes to this policy will be published on this page with an updated date.
